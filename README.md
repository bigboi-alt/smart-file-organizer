# 📁 Smart File Organizer (Python)

A Python-based command-line tool that automatically organizes files in any folder based on file type.  
It helps keep directories like **Downloads** clean by sorting files into categorized folders safely and efficiently.

---

## 🚀 Features

- Organizes files by type (Images, Videos, Documents, Audio, Code, etc.)
- Works on **any folder** using command-line arguments
- Prevents file overwriting with automatic duplicate handling
- Creates folders automatically if they don’t exist
- Simple, fast, and reliable
- Uses only Python standard libraries

---

## 🛠️ Tech Stack

- **Python**
- `os`
- `shutil`
- `argparse`

(No external dependencies required)

---

## 📂 File Categories

| Category    | File Types |
|------------|-----------|
| Images     | `.jpg`, `.png`, `.gif`, `.webp` |
| Videos     | `.mp4`, `.mkv`, `.avi`, `.mov` |
| Documents  | `.pdf`, `.docx`, `.txt`, `.xlsx` |
| Audio      | `.mp3`, `.wav`, `.aac` |
| Archives   | `.zip`, `.rar`, `.7z` |
| Code       | `.py`, `.js`, `.cpp`, `.html`, `.css` |
| Others     | Any unsupported file type |
